# Vibe Color Studio · 设计规范

> **用途：** 视觉与交互的单一参考。改 UI 时先对本文，再改代码。  
> **实现真源：** `src/index.css` 的 CSS 变量与工具类。  
> **产品/工程上下文：** [PROJECT_REFERENCE.md](./PROJECT_REFERENCE.md)

---

## 1. 设计原则

1. **近黑极简，饱和色只出现在预览里。** Chrome（顶栏、右栏、工具栏）去色；手机框里的渐变 / 纯色底才是唯一高饱和区域。
2. **秩序靠对齐和层级，不靠描边堆量。** 分隔用 1px 发丝线；不要用厚边框、大投影、彩色描边做结构。
3. **8px 节奏。** 间距、控件高度优先走 8 的倍数（8 / 16 / 24 / 32 / 36 / 40）。
4. **数字是测量值。** HEX、对比度、L/C/H 用等宽数字（`.num`），避免数字跳动。
5. **一眼能决策，细节进 hover。** 对比度默认 `4.5:1 + 徽章`；完整 WCAG / APCA / 文字色放 `title`。
6. **两套模式两套 UI。** HEX 是动态渐变工具；图片是纯色取色工具。不要把渐变控件塞进图片 Tab。
7. **预览叠层克制。** 上传图要小、无阴影；圆角连续平滑，不要「切出来的圆角」。

## 2. 色彩

| Token | 值 | 用途 |
|-------|----|------|
| `--bg` | `#08080a` | 舞台 / 顶栏底 |
| `--bg-rail` | `#0a0a0d` | 右侧栏 |
| `--bg-elev` | `#101014` | 弹窗 |
| `--bg-float` | `rgba(20,20,25,0.72)` | 玻璃工具栏 |
| `--line` | `rgba(255,255,255,0.07)` | 发丝线 |
| `--line-2` | `rgba(255,255,255,0.12)` | 控件边、色块边 |
| `--line-3` | `rgba(255,255,255,0.20)` | 焦点 / 激活边 |
| `--ink` | `rgba(255,255,255,0.94)` | 主文案、HEX |
| `--ink-2` | `rgba(255,255,255,0.56)` | 次文案、滑块标签 |

## 3. 字体

| 场景 | 字体 | 说明 |
|------|------|------|
| Chrome | Urbanist Variable | 顶栏、右栏、工具栏、弹窗 |
| 手机 Mock / 叠图标题 | TikTok Sans | 缺字回退 Urbanist，再系统黑体 |
| 代码 | 系统等宽 | `.codeblock` |

**字号阶梯（常用）：**

| 角色 | 大小 | 字重 | 其它 |
|------|------|------|------|
| 顶栏标题 | 14.5px | bold | tracking -0.02em |
| 分区标签 `.micro` | 9px | 600 | 0.16em 大写 |
| 主 HEX | 13px | semibold | tracking 0.02em · `.num` |
| 控件标签 | 12px | medium | `--ink-2` |
| 元数据 L/C/H | 10.5px | regular | `.num` · `--ink-3/4` |
| 叠图标题 | 16px | bold | 居中、白字、TikTok Sans |
| 叠图 Ratio / 底部 HEX | 11px | medium | Urbanist · 文字 40% 白；胶囊描边 20% 白、fill 4% 白 |
| 快捷键 Kbd | 10px | semibold | |

中文与英文共用同一套 chrome 字体；不要为中文另开衬线。

## 4. 圆角与 Corner Smoothing

**所有矩形容器统一 Figma Corner Smoothing 60%。**

| | 值 |
|--|--|
| Figma | Corner smoothing **60%** |
| CSS | `corner-shape: superellipse(1.6)` |
| Token | `--corner-n: 1.6` |
| 工具类 | `.smooth-r`（加在已有 `border-radius` 上） |
| 色块 | `.color-swatch`（36×36，半径 `--r-sm`，自带 smoothing） |

**半径阶梯：**

| Token | 值 | 用在 |
|-------|----|------|
| `--r-xs` | 6px | 小按钮、徽章、语言档 |
| `--r-sm` | **8px** | **色块、HEX 输入、上传区、分段选中态** |
| `--r-md` | 10px | 分段轨道、主按钮；手机叠图 |
| `--r-lg` | 14px | 少用 |
| `--r-xl` | 18px | 弹窗 |
| `999px` | 胶囊 | 底栏工具条、圆形箭头（**不要**加 superellipse） |

**提取色容器（必须一致）：**

- HEX 色块 = 图片提取色块 = `ColorSwatch`（8px + 60% smoothing）
- 旁边的 HEX 输入框同样 8px + 60% smoothing
- 不要把提取结果做成 12px、输入做成 8px

**例外：** `rounded-full` 的胶囊 / 圆点保持正圆，不加 `.smooth-r`。

不支持 `corner-shape` 的浏览器回退为普通圆角，半径仍要一致。

## 5. 间距与控件尺寸

| 元素 | 尺寸 |
|------|------|
| 顶栏 | 高 56px |
| 右栏 | 宽 320px，分区左右 padding 20px |
| 色块 | 36×36 |
| HEX 输入 | 高 36px |
| 分段控件 | 轨道 + 4px padding，按钮高 32px |
| 底栏按钮 | 高 32px |
| 主按钮 | 高 44px |
| 发丝分隔 | 1px，高 20px（工具栏内） |

控件之间 gap 常用 `8px` / `10px` / `12px` / `14px`。分区之间用发丝线，不要用大色块分隔。

## 6. 布局

```
顶栏 56px：品牌 · 副标 ·（HEX 快捷键）· 中/EN
左：预览舞台（负空间）+ 底悬浮胶囊工具栏
右 320px：输入 / 渐变 / 光斑布局（折叠）/ 导出
```

- 预览居中，周围留空；不要在舞台上再堆状态卡片。
- 工具栏悬浮在预览下方，玻璃拟态 + 发丝边，**不要**做成贴底实心条。
- 导出代码用居中弹窗，不要常驻右栏。

## 7. 组件规则

### 色值 / 提取结果

- 左：36×36 色块；右：HEX 输入（优先）
- 元数据：`H 228°` · `C 0.211`
- **色相**滑杆在 HEX 下方，默认折叠；拖动必须同步色块与 HEX
- 图片结果额外一行：白字对比度、采样数、候选数
- 提取中只显示极小「生成中」，不要骨架屏或进度条

### 分段控件（HEX | 图片、中文 | EN）

- 发丝胶囊轨道 + 内嵌选中块
- 选中：`bg-white/10` + 白字；未选：`--ink-3`
- 语言开关更小一号，放顶栏最右

### 底栏

- HEX：‹ Dark/Light › · 当前帧 · 导出代码 · 对比度 · 眼睛
- 图片：当前帧 · 相对白字对比度 · 眼睛（无明暗、无导出代码）
- 对比度一位小数；徽章用语义色（绿 AAA / 蓝 AA / 琥珀大字 / 红未达标），仍保持低饱和

### 手机叠图（图片模式）

- 纯色底，无光斑、无阴影；未上传时默认底色 `#2A2A2A`
- 图：固定半屏宽正方形槽，图在槽内居中（不同比例共用中心点）
- 槽顶边约 68px
- 圆角 10px + 60% smoothing
- 标题在槽下约 16px：TikTok Sans，白字 16px bold
- 标题下来一行半透明小字：`Ratio: W:H`（Urbanist 11px，由像素宽高约分）
- 标题来源：有意义的文件名；否则占位符 `Lorem Ipsum`（不做 OCR）
- 底部色值胶囊：始终展示（含未上传），`0.5px` 描边 20% 白、文字 40% 白（与 Ratio 一致）+ `4%` 白 fill，Urbanist 11px

### 弹窗

- 近黑底、发丝边、大圆角 18px + smoothing
- 遮罩 `black/62` + 轻 blur
- 白底「复制代码」与右栏主按钮同一套反相强调

## 8. 动效

- 入场：`cubic-bezier(.2,.8,.2,1)`，位移 6–8px，时长 0.24–0.5s
- 控件：只过渡 `color` / `background` / `scale`，不要乱加弹性
- 光斑动画只存在于 HEX 预览；图片模式静止纯色
- `prefers-reduced-motion: reduce` 时关掉入场动画

---

## 9. 可访问与对比度

- HEX 预览：文字 vs 底/光斑最差对比度，目标 ≥ 4.6:1
- 图片纯色：白字对比度目标 ≥ 9:1（取色管线保证）
- 焦点环：白 3px，外垫 1px `--bg`，不要浏览器默认蓝环
- 图标按钮必须有 `aria-label`

---

## 10. 不要做

- 给叠图或色块加 drop shadow
- 提取色块用与 HEX 色块不同的半径
- 在 chrome 里使用彩色渐变、霓虹、厚投影
- 图片 Tab 显示丰富度 / 光斑布局 / 明暗 / 导出 CSS
- 把 Feed Mock 的 TikTok Sans 用到右栏
- 用 `127.0.0.1` 预览（用 `localhost`）
